**App Name: Vocab Buddy**

Description:
An educational application designed to help students learn English vocabulary interactively, tailored to different ages and difficulty levels. It uses AI to generate topic-based vocabulary with translations, example sentences, and text-to-speech pronunciation, while tracking learning progress through practice modes and visual dashboards.
Features:
Multi-User Profiles: Supports adding multiple learners with fun avatars. Each user has their own isolated history, favorites, learned words, and quiz statistics, allowing siblings or classmates to share the same device.
AI Vocabulary Generation: Generates 10 English vocabulary words based on a user-provided topic, age group, and difficulty level. It provides the English word, Arabic translation, and a simple English example sentence.
Smart Avoidance: The app remembers previously generated words for a specific topic, age, and difficulty, ensuring that it provides fresh vocabulary every time a user requests the same topic.
Interactive Word Cards: Displays words with a clean design. Includes a Text-to-Speech (TTS) button to hear the pronunciation, and a star icon to save words to a Favorites list.
Learning History: A timeline view of all past generated word lists, grouped by topic and date. Users can expand entries to review the words or use the "Reset All" button to clear their history.
Calendar View: A visual monthly calendar that highlights days with learning activity. Clicking on an active day reveals the exact vocabulary lists generated on that date.
Practice Area:
Decks: Automatically organizes words into study decks, including "All Words", "Favorites", and individual decks for each topic.
Flashcard Mode: A 3D flip-card interface to study words. Includes text-to-speech and a "Mark as Learned" toggle to track which cards the student has mastered.
Quiz Mode: A multiple-choice quiz game that tests the user on the Arabic translations of the words in the selected deck.
Visual Dashboard (Stats):
KPI Metrics: Displays total words learned, favorite words, quizzes taken, and average quiz score.
Charts: Includes a Bar Chart for the last 7 days of words learned, a Line Chart tracking quiz performance trends, and a Pie Chart breaking down vocabulary by difficulty.
Streak Tracker: Displays the total number of active learning days to encourage consistency.
